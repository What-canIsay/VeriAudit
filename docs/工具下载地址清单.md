# VeriAudit 所用工具下载地址清单

> 依据仓库根目录 **`LAUNCH.md`** 的部署流程整理，版本为本机满血实测的一套。
> 约定：重型工具与模型缓存统一装在 **D 盘**（`D:/Tools/*`），保持 C 盘干净。
> 配置列含义：**PATH** = 需加入「启动后端那个终端」的 PATH；**自动探测** = 放到指定目录即可、无需入 PATH；**pip/pipx/npm** = 由包管理器安装。

## 六、前端依赖与沙箱镜像

**前端依赖**：`cd frontend && npm install` 由 `package.json` 统一安装（React + TypeScript + Vite；npm 源 https://www.npmjs.com/ ）。

**Docker 基础镜像**（来自 Docker Hub，需手动预拉，系统不自动拉基础镜像以省 C 盘）：

```powershell
docker pull python:3.11-slim   # 沙箱/搭建基础镜像（~189MB，必需）
docker pull node:20-slim       # 审 JS/TS 项目时的沙箱 CLI 镜像（按需）
```
- `python:3.11-slim` — https://hub.docker.com/_/python
- `node:20-slim` — https://hub.docker.com/_/node

**沙箱内动态验证/攻防工具**：首次做动态复现/环境搭建时，系统基于 `python:3.11-slim` **自动构建**搭建/验证镜像（apt 装入以下工具，一次性、约 2~4 分钟、成品约 1.8GB，**无需手动下载**）：

| 工具 | 用途 | 上游主页 | 获取方式 |
|---|---|---|---|
| gcc / build-essential | 原生目标构建（含 libasan） | https://gcc.gnu.org/ | 镜像内 apt |
| clang / compiler-rt | 原生构建、`-fsanitize` 链接 | https://clang.llvm.org/ | 镜像内 apt |
| AddressSanitizer / UBSan | 原生内存/未定义行为取证判据 | 随 GCC/Clang 提供 | 镜像内（`-fsanitize=address,undefined`） |
| GDB | 原生崩溃栈帧观察 | https://www.sourceware.org/gdb/ | 镜像内 apt（容器授 `SYS_PTRACE`） |
| strace | 系统调用级运行时观察 | https://strace.io/ | 镜像内 apt |
| sqlmap | SQL 注入确认/利用 | https://github.com/sqlmapproject/sqlmap | 镜像内 apt |
| default-mysql-client | 白盒通用日志回读、seed 数据 | https://www.mysql.com/ | 镜像内 apt |
| netcat / socat / jq | 非 HTTP 网络验证、数据处理 | Debian 软件包 | 镜像内 apt |
| nuclei | 模板化配置/暴露类验证 | https://github.com/projectdiscovery/nuclei | 镜像内**尽力下载**（失败则缺席，不影响构建） |
